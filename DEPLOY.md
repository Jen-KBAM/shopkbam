# Publish with GitHub Pages

1. Create a free GitHub account.
2. Create a public repository named `shopkbam`.
3. Upload all contents of this folder. Keep `index.html` at the repository root.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. In the Pages custom-domain field, enter `shopkbam.com`.
7. Add the exact DNS records GitHub displays at the company where you purchased the domain.
8. After verification, enable **Enforce HTTPS**.

Before sharing the site, test every button, submit a test order, test payment, and check the mobile layout.
